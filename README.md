# tiny-chess

A chess engine in 4 KB of Python (main.py), built for make.fun
tiny-chess-01. Negamax alpha-beta with a transposition table,
PVS, LMR, null-move pruning, check extensions and quiescence;
piece-square evaluation with passed-pawn and rook-file terms.
Deterministic: fixed node budget, no clock.
